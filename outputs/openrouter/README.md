# BehaviorBench evaluation — `tencent/hy3`

Full-sample run of the BehaviorBench suite against **Tencent Hunyuan 3 (`tencent/hy3`)**
via OpenRouter. Tencent is not in the paper's leaderboard, so this extends coverage to a
previously unrepresented Chinese lab.

**Everything published here is the program's own output.** No metrics were recomputed,
re-averaged, or reformatted by hand.

### The single command

The tool runs one task per invocation. This is the whole thing:

```bash
uv run behaviorbench-eval \
  --task game_behavior_dictator \
  --model-type openai \
  --model-name tencent/hy3 \
  --api-base https://openrouter.ai/api/v1 \
  --concurrency 4 \
  --output-dir outputs/openrouter
```

[`run_full.sh`](run_full.sh) is that command in a loop over all 39 task names, plus retry-on-429
and logging so it could run unattended for ~4 hours. Nothing else.

### Reproduce

```bash
bash outputs/openrouter/run_full.sh                          # ~4h, ~$1.40
uv run python outputs/openrouter/show_results.py             # re-render RESULTS.txt
```

> **Note on the code version.** `--model-type openai` was broken before commit `690c1b6` —
> it built an Azure client pointed at localhost and failed every call. That fix
> ([PR #1](https://github.com/umich-foreseer/behaviorbench_eval/pull/1)) is what made this run
> possible; earlier code cannot reproduce it.

## What's in a result JSON

Each file in [`tencent/hy3/`](tencent/hy3) contains, per sample:

```json
{
  "prompt":            {"system": "...", "user": "You are paired with another player..."},
  "raw_output":        "I would keep $50 and give the other player [$50].",
  "parsed_prediction": 50.0,
  "expected":          null
}
```

plus `metrics` (computed by the program), `metadata` (sample counts, parse failures,
model/human means and standard deviations), `inference_settings`, and `token_usage`.

Every headline number can be traced back to these files.

## A note on aggregation

An earlier version of this page reported **family-level averages** (mean MAE per family, etc.).
Those have been removed. The program computes metrics **per task**, and does not aggregate
across separate invocations — so any family average is an added assumption, not program output.

That assumption is not trivial: the raw JSONs carry two MAE variants,
`MAE_with_normalization_mae` (normalised to a common scale) and `..._mae_raw` (each game's
native units). Averaging the raw form across games sums incommensurable units, since
`push_pull` is effectively binary while `trust_banker` runs 0–100+. The choice changes the
acrossgame figure from 22.95 to 30.28.

Rather than pick a convention, this page publishes the per-task numbers as the program
reports them. Aggregate them however the paper does.
